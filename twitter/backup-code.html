推特备用码是什么、在哪看、怎么用：推特账号双重验证丢了怎么登录

更新于 2026-09-29 · 阅读约 8 分钟

推特账号开了双重验证以后，登录要过两道门：密码，加上一个验证码或安全密钥。第二道门平时靠手机，手机一丢、号码一换、短信收不到，人就被关在门外。备用码就是为这种时候准备的应急钥匙。这篇把它讲透：是什么、在哪看、怎么生成、怎么用，以及用了一次之后再登录为什么会报错。

文中的菜单名和规则取自 X 官方帮助中心的《如何使用双因素认证》和《双因素认证验证帮助》两篇。简体中文界面里「双重验证」写作「双因素认证」，下文两种说法指同一个功能；没有中文译名的菜单保留英文原文。

一、先弄清双重验证有哪三种方式

官方对双因素认证的定义是：登录不再只靠密码，还要再输入一个验证码或使用安全密钥，确保只有你本人能进账号。开启时会要求你的账号有一个已确认的邮箱，没有的话会先让你填邮箱、收确认码。

方式第二道门是什么要准备什么
短信登录时发到手机的六位数代码账号绑定一个能收短信的手机号；没绑的话开启时会提示你填
认证应用验证器 App 里每隔一段时间变化的验证码任意一款基于时间的一次性密码（TOTP）应用，官方举例 Google Authenticator、Authy、Duo Mobile、1Password；开启时扫二维码绑定
安全密钥一把实体密钥，插 USB 或走蓝牙、NFC，触按按钮一把密钥；电脑端要用最新版的 Chrome、Edge、Firefox、Opera 或 Safari

三种方式可以同时开。登录时系统默认要求你用上一次登录用过的那种方式，登录页面上还会给出「选择不同的双因素认证方法」的选项，点一下就能切换。所以同时开两种，就等于多一条退路。

推特号的卡密里常见的那串「2FA 密钥」，对应的就是上表里的「认证应用」：把它填进验证器 App，就能算出登录要的验证码。它是认证应用的钥匙，不是备用码，两者别混。

二、推特双重验证怎么设置

电脑端的入口路径是：左侧菜单点「更多」→「设置和隐私」→「安全和账号访问」→「安全」→「双因素认证」。手机端从主菜单进「设置和隐私」，后面几步相同。进去之后勾选想用的方式，按提示输入密码、确认邮箱，再按方式分别完成：

方式设置过程的关键一步
短信输入短信收到的确认码后，确认页面上会直接显示一个备用码。官方建议截图保存，丢手机或换号码时靠它登录
认证应用用验证器 App 扫描页面上的二维码，点「下一步」，再把 App 生成的验证码填回去点「验证」
安全密钥插入或配对密钥、触按按钮，按屏幕提示完成。之后可以在「管理安全密钥」里改名、删除或再加一把

官方还有一句容易被忽略的话：如果你加了安全密钥，就不再强制要求开别的备用方式，安全密钥可以作为唯一的认证方法。这对自己用的账号是省事，但也意味着那把密钥一丢，手上就没有别的退路，除非你另外生成过备用码。

三、推特备用码是什么，和临时密码有什么不同

按官方说法，通过 iOS 或 Android 版 X 应用开启双因素认证时，系统会自动为你生成一个备用码；在 x.com 上也可以自己生成。它的用途只有一个：手机丢了或换了号码、第二道门过不去的时候，用它代替验证码登录。

和它长得像的是临时密码，官方特意写了「备用码和临时密码不是一回事」：

备用码临时密码
用来做什么过不了第二道门时，代替验证码登录开了双重验证后，在其他要求输入 X 密码的设备或应用上登录，代替原密码
在哪里能用x.com、mobile.x.com、iOS 和 Android 版 X 应用及其他 X 客户端其他要求输入 X 密码的设备或应用；登录 iOS、Android 版 X 应用和 mobile.x.com 时不需要
有效期官方没写固定时长，但有「有效」与「失效」之分，见第五节一小时后过期
从哪生成X 应用或 x.com「双因素认证」页面「其他方法」（Additional methods）下的「临时密码」

一句话区分：备用码是给「进不去」准备的，临时密码是给「第三方要密码」准备的。

四、推特备用码在哪里看、怎么获取

先说一个常见的误会：已经生成的备用码，事后没有地方可以「查看」。官方的建议是在它出现的时候就抄下来、打印出来或截图保存。你在网上搜「推特备用码哪里看」，真正能做的是「重新生成一个」。

官方给出的 App 端生成路径：进入「设置和隐私」（iOS 点个人资料图标，Android 点导航菜单图标或个人资料图标）→ 点「账号」→ 点「安全」→ 点「备用码」（Backup code）。新版界面把菜单名改成了「安全和账号访问」→「安全」→「双因素认证」，如果路径对不上，就在这几层安全相关的页面里找「备用码」这一项。

注意：生成备用码的前提是你现在还登录着。备用码是给将来进不去的时候用的，等到已经进不去了再想起来生成，就晚了。

五、推特备用码怎么用：顺序比码本身更要紧

官方写的使用步骤很简单：用平常的用户名和密码登录，看到「已发送双因素认证请求」的提示时，点页面上输入备用码的链接，把备用码填进去即可。

真正容易出错的是下面两条规则，官方原文写在同一段注释里：

规则意味着什么
同一时间最多可以有五个有效的备用码生成过好几次的话，手上可能同时有几个都能用的码
必须按生成的先后顺序使用；不按顺序用，会让之前生成的所有备用码作废如果你跳过旧码直接用了最新的一个，更早生成的那些就全部失效

这也解释了百度上常见的那个问题：推特备用码使用了，再次登录登不上。官方写明，用一个已经失效的备用码，或者不按顺序使用备用码，都会看到报错，这时只能重新生成新的备用码。所以一个稳妥的习惯是：每次靠备用码登录进去以后，先重新生成一个新的备用码存好，再做别的事。

对买来的推特号，这条顺序规则还有另一层用处：你不知道卖家或上一任使用者手里是否留有该账号生成过的备用码。按官方这条顺序规则推下来：你自己新生成一个码，并用它登录过一次，比它更早生成的码就属于被跳过的旧码，会一并作废。

六、推特备用码忘记了、手机丢了怎么办

官方帮助按具体情况分别给了处理办法，整理如下：

情况官方给的办法
手机丢了，手上有备用码用备用码登录，然后在手机设置（Mobile settings）里更新号码
手机丢了，已经退出登录，也没有有效备用码联系 X 的支持团队求助
只开了短信验证，而且电脑上还登录着在 x.com 的手机设置里点「删除我的手机」（Delete my phone），双因素认证会随之自动关闭
换了新手机换机前先备份旧手机，好在新手机上恢复 App 会话。iOS 建议做加密备份来保留 App 密钥，官方说只靠 iCloud 备份通常保不住；也可以在旧手机或还登录着的 x.com 上先关掉双因素认证
收不到短信验证码短信可能延迟，至少等两分钟再重试；换过号码或运营商要先改设置，进不去就先用备用码登录
手机没网或开了飞行模式在 X 应用里「设置和隐私」→「账号」→「安全」→「登录代码生成器」（Login code generator）取码登录

整张表里最没有退路的是第二行，能否避开它，取决于出事前有没有留好备用码或开第二种验证方式。

七、买来的推特号，到手后先做这几件事

买来的推特号通常已经开着双重验证，交付的是「账号 + 密码 + 2FA 密钥」这一类组合。登录成功之后，先把应急钥匙换成自己的：

顺序做什么为什么
1用卡密里的 2FA 密钥在验证器 App 里算出验证码，完成登录这是交付时约定好的第二道门
2马上生成一个自己的备用码，抄下来或截图，和密码分开存放之后换设备、验证器出问题时，靠它进号
3把 2FA 密钥也存进另一个验证器或另一台设备密钥只存在一个 App 里，那台手机就成了唯一的门
4在「双因素认证」页面确认当前开着哪几种方式只开一种就只有一条路，官方的切换入口只在你开了多种时才有用

账号刚到手就被要求验证手机号或邮箱，那是另一回事，属于账号被锁定，处理顺序见推特账号被锁定、受限、封停的区别与处理。

常见疑问

问题回答
推特备用码在哪里看生成后没有地方回看，只能在出现时保存；丢了就在登录状态下重新生成
备用码用过之后再登录报错用了失效的码或没按生成顺序用都会报错，需要重新生成；登录进去后先生成新码存好
登录第三方工具能用备用码吗不能。官方写明第三方应用要用临时密码，临时密码一小时后过期
备用码和卡密里的 2FA 密钥是一回事吗不是。2FA 密钥用来在验证器 App 里生成验证码，备用码是验证器用不了时的替代

小结

双重验证把推特账号的门加了一道锁，备用码是这道锁的备用钥匙。它只能在还登录着的时候生成，生成后没有地方回看，并且要按生成顺序使用。这三条记住了，「手机丢了进不去」「用过一次再登录报错」这两类问题基本就不会发生。买来的推特号尤其要趁刚登录进去，把备用码换成自己手里的那一份。

需要现成账号的话，桃子出海的推特 X 账号商品页会写明卡密包含哪些字段（2FA 密钥、辅助邮箱与邮箱密码等），下单自动发货。到手登录后，按本文第七节先把备用码换成自己的。
